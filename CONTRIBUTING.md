# Contributing to SwarmKillChain

Thanks for your interest in contributing.

## How to Contribute

1. Search existing issues before creating a new one.
2. Open an issue for bugs, enhancements, or discussions.
3. Fork the repository and create a focused branch.
4. Submit a pull request with a clear description and test notes.

## Development Guidelines

- Keep changes scoped and reviewable.
- Prefer small, composable modules.
- Document assumptions and security implications.
- Add or update tests when behavior changes.

## Commit and PR Guidelines

- Use descriptive commit messages.
- Reference related issues (e.g., `Closes #123`).
- Include:
  - What changed
  - Why it changed
  - How it was validated

## Code Style

- JavaScript/TypeScript: follow existing lint/format rules.
- Python: follow PEP 8 and project conventions.

## Security Notes

- Do not commit secrets, tokens, or private keys.
- Use environment variables for credentials.
- Report sensitive findings privately to maintainers.

## Review Process

Maintainers will review for correctness, safety, and maintainability. Feedback may request revisions before merge.
