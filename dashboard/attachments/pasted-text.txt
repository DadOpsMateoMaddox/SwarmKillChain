There's no separate "Python version of me" — same model, same per-token price either way. The real cost levers are:
Subscription vs API: If you have a Claude Max plan, claude -p calls draw from that quota (effectively flat-rate). If you use the Python SDK with an API key, it's pay-per-token. For a loop that might run dozens of turns, the Max plan is much cheaper if you have one.

Bottom line: CLI on Max is cheapest if you have it; SDK is more controllable but only wins on cost via aggressive Haiku routing + caching. I'll make the orchestrator CLI-based with per-role model selection.

# Architecture
 
## Roles
 
1. **Investigator** forms hypotheses and requests typed read-only tools.
2. **Skeptic** independently checks the cited evidence and tries to refute each
   finding.
3. **Alternative narrative** searches for competing explanations and coverage
   gaps.
4. **Report gate** accepts only findings with valid tool-call references,
   evidence hashes, confidence, and review status.

internal belief

delegation
      ↓
next action
